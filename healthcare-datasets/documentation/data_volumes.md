# Data volumes and locations

Generated by `python -m hcds.volumes` from the acquisition manifest, `logs/validation_log.csv` and the catalogue records. Do not edit by hand.

- **Downloaded:** 27 datasets, 28 files, 6.57 GB. Files sit under `healthcare-datasets/<category>/<subcategory>/raw/<ID>/` and are git-ignored, so run `python -m hcds.pipeline` to fetch them on a new machine.
- **Snowflake:** 5 catalogue entries. The tables stay in the owner's Snowflake account; only aggregate profiles (cells with n<11 suppressed) are written to the git-ignored `snowflake/raw/` folder.
- Every other catalogue entry is metadata only (no data held).
